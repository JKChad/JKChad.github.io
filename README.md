## NIGHT SHIFT

Playable Three.js vertical slice of a co-op stealth-action game:

```bash
cd night-shift
npm install
npm run dev
```

Open the local Vite URL, then **Accept Contract**.

Design pillars: shared attention meter, light-as-map stealth, stealth→loud hard-cut, economy-as-difficulty.
